# Antenna-Design-MATLAB
# Antenna Design Using MATLAB

## Project Overview

This project focuses on the design and simulation of an antenna using MATLAB Antenna Toolbox and the Antenna Designer application.

The antenna geometry was created and modified by adjusting its physical dimensions to study their influence on antenna performance.

## Software Used

- MATLAB
- Antenna Toolbox
- Antenna Designer

## Antenna Specifications

- **Antenna type:** Helix
- **Operating frequency:** 1.8 GHz
Radius = 0.0280

Width = 0.0012

Turns = 4

Spacing = 0.0350

GroundPlaneRadius = 0.0750
- **Reference impedance:**  50 Ω

## Project Objectives

- Design an antenna using MATLAB Antenna Designer.
- Adjust antenna dimensions.
- Analyze the antenna input impedance.
- Investigate antenna resonance and impedance matching.
- Examine the radiation pattern.

## Simulation Results

The following antenna characteristics can be analyzed:

- Input impedance
- Reflection coefficient (S11)
- VSWR
- Radiation pattern
- Antenna directivity and gain

Simulation results and figures will be added as the project develops.

## How to Run

1. Open MATLAB with Antenna Toolbox installed.
2. Download the MATLAB script from this repository.
3. Run the script to recreate the antenna model.
4. Perform antenna simulations and analyze the results.
